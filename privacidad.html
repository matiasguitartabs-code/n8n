Política de privacidad de matias cloud

Última actualización: 29 de octubre de 2026

Qué es esta aplicación

matias cloud es una integración de uso personal que conecta una instancia de n8n con la cuenta de Google de su propietario para automatizar tareas propias. No se ofrece a terceros.

Qué datos se usan

Con la autorización expresa del usuario, la aplicación puede acceder a:

  • Gmail: leer, redactar y enviar correos y borradores.
  • Google Sheets: leer y editar hojas de cálculo.
  • Google Drive: acceder a los archivos que se usan con la aplicación.

Para qué se usan

Los datos se usan solo para ejecutar las automatizaciones que configura el propio usuario. No se usan para publicidad, no se venden y no se ceden a terceros.

Almacenamiento

Los datos se procesan en la instancia de n8n del usuario. Las credenciales de acceso se guardan cifradas en esa instancia. No se guardan copias en otros servidores.

Uso limitado de los datos de Google

El uso y la transferencia de la información recibida de las API de Google cumplen la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de Uso Limitado.

Cómo retirar el acceso

Puedes revocar el acceso en cualquier momento desde myaccount.google.com/permissions. Para pedir que se borren datos, escribe al correo de contacto.
